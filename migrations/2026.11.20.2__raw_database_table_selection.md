# Raw Database Table Selection

Version: `2026.11.20.2`

## Accepted Contract

Treat requests for `raw` / `рау` database data as direct read-only selections
from the requested table. Return actual stored rows with their original column
names and values, rather than summaries or transformed data.

## Apply

1. Merge the raw database selection rule from
   `patterns/AGENTS_RUNTIME/07-scope-and-evidence.md` into the corresponding
   local data-handling rules and its loading pointer from
   `patterns/AGENTS_RUNTIME/04-content-and-authoring.md`. Keep the full rule in
   the scope/evidence module to preserve the authoring module's context budget.
   Preserve project-specific access and secret boundaries.
2. Preserve NULLs, empty strings, duplicates and stored precision. Do not add
   aggregations, joins, calculations, deduplication, renaming, normalization,
   filters, projections or ordering that the user did not request. Select all
   columns when the user does not specify columns.
3. Identify the source table and executed query. Disclose pagination, row limits,
   truncation, withheld fields and unavoidable display conversions. Report
   unavailable database access and label illustrative SQL/data explicitly;
   never claim that a query was executed when only an example was prepared.
4. Set fresh-bootstrap template version/checkpoint to this release after file
   delivery. Preserve unrelated project instructions and metadata.

## Verify And Record

- Inspect the installed rule against the accepted contract and check that an
  unfiltered raw request maps to a direct all-column table selection, while
  requested filters remain supported and partial results remain explicit.
- Run whitespace checks. For source maintenance, run release-order, routing,
  task-verification and bootstrap checks against the fixed prior release ref.
- Record installation only after file checks pass. No database connection or
  product data read is required to install this instruction-only migration;
  illustrative query examples are not live database verification.

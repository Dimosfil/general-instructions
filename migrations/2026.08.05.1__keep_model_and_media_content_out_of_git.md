# Keep Model And Media Content Out Of Git

Migration ID: `2026.08.05.1__keep_model_and_media_content_out_of_git`

## Purpose

Prevent LLM/model files, media, datasets, archives, and similar large binary
content payloads from bloating repositories or being pushed to Git remotes.

## Accepted Guidance

- Never add, stage, commit, or push LLM or other model weights/checkpoints,
  photos, video, audio, datasets, archives, or similar large binary content
  payloads.
- Keep prohibited content outside Git in project-approved artifact or object
  storage. Commit only compact manifests, source URLs, checksums, or retrieval
  instructions needed to locate or reproduce it.
- Before staging, inspect untracked and unusually large files. Add appropriate
  project-local ignore rules when prohibited content exists or may be generated.
- Do not silently remove content that is already tracked or rewrite repository
  history. Report it and obtain approval for the exact cleanup operation.
- Allow an exception only when the user explicitly approves the exact content
  and Git storage approach for the current project.

## Conflict Handling

If prohibited content is already tracked or present in repository history, do
not delete files or rewrite history automatically. Report the affected paths and
size, then ask for approval before a scoped removal or history-cleanup plan.

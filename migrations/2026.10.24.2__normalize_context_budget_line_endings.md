# Normalize Context Budget Line Endings

Version: `2026.10.24.2`

## Purpose

Give LF, CRLF, and mixed text the same context-budget measurement without
increasing thresholds or rewriting project source files.

## Apply

1. Merge the normalization changes from source `tools/get-gi-context.ps1` into
   the project copy: normalize CRLF to LF before section and final-packet
   counting/truncation; reserve one logical trailing LF. Preserve project hooks.
2. If the project carries `tools/test-gi-context-routing.ps1` or
   `tools/test-instruction-kit-bootstrap.ps1`, merge their normalized budget
   measurement and regression cases. File limits count UTF-8 bytes of normalized
   text; packet limits count normalized characters. Preserve local tests.
3. Do not change `config/gi-context-budgets.json`, unrelated whitespace, stored
   source line endings, preferences, or task scope. Source maintenance also
   updates README, the existing context-pipeline memory contract, version,
   changelog, and metadata templates.

## Verify And Record

- Compare LF, CRLF, and mixed input through the public builder; require equal
  normalized output, section truncation, and enforcement of the final cap.
- Check the exact normalized UTF-8 byte boundary and reject a real overflow.
  Confirm configured budget values remain unchanged. Run applicable routing
  and installed-kit bootstrap checks and `git diff --check`.
- Merge idempotently, preserving customizations. On conflict, report the
  affected operation and leave the migration pending. Only after verification,
  record version `2026.10.24.2` and this migration in compact migration state.

# Restore Lazy Startup Context

Migration ID: `2026.09.22.3__restore_lazy_startup_context`

## Purpose

Restore the useful startup/restore behavior that was accidentally removed when
`agent-start.ps1` became a thin wrapper, while keeping one context-builder call
and enforceable output budgets.

## Accepted Guidance

- Keep `tools/agent-start.ps1` as a compatibility wrapper over
  `tools/get-gi-context.ps1`; do not restore separate update, file, summary, and
  Git tool loops.
- For the plain `start` route only, lazily emit bounded project `AGENTS.md` and
  working-agreement sections when those files exist.
- Restore compact Git-commit and system-language preference notices.
- Select handoff summaries only from `*_AGENT_WORK_SUMMARY.md`, ordered by
  `LastWriteTime` descending. Do not select unrelated Markdown files.
- Restore compact Git state, runbook command hints, and the legacy
  `index_project.py` memory-search hint when their source files exist.
- Keep every file and hint section line-bounded, and enforce the total start
  packet through `config/gi-context-budgets.json`.

## Source Files And Project Targets

- Copy `tools/get-gi-context.ps1`, `config/gi-context-budgets.json`, and
  `tools/agent-start.ps1` from the shared source/template.
- Preserve project-local instruction, working-agreement, preference, summary,
  runbook, and memory files; the builder reads them but does not rewrite them.
- Advance instruction-kit metadata only after the restored behavior passes its
  regression tests.

## Verify

- Confirm the normal start packet contains project entrypoint, working
  agreements, commit preferences, system-language preferences, canonical
  summary, Git snapshot, runbook hints, and memory search whenever their source
  files exist.
- Confirm unrelated summary Markdown is ignored and the newest canonical
  summary is selected by modification time.
- Confirm non-start routes do not receive startup-only sections.
- Run `tools/test-gi-context-routing.ps1`,
  `tools/test-instruction-kit-bootstrap.ps1`, PowerShell syntax checks, and
  `git diff --check`.

## Rollback

Remove the restored startup-only sections and return the wrapper/builder/budget,
metadata, version, and changelog together. Do not restore multiple tool-loop
startup execution.

# Separate Build Output From Source Git

Migration ID: `2026.10.03.1__separate_build_output_from_source_git`

## Purpose

Keep rebuildable build artifacts separate from maintained inputs and out of
source Git repositories without breaking startup, packaging, or deployment.

## Accepted Guidance

- Generate application builds, frontend bundles, installers, and intermediate
  output into dedicated ignored directories with documented configurable paths.
- Keep source, required source assets, manifests, lockfiles, build configuration,
  and build/packaging scripts versioned. Classify generated source, database
  migrations, and mixed public/static directories before excluding anything.
- During authorized build cleanup, update consuming paths and remove only
  confirmed tracked output from the index, preserving local and unrelated files.
  Commit these scoped removals through the authorized Git workflow.
- Verify clean-checkout generation and affected consuming workflows; check that
  output is ignored and untracked. Publish required artifacts through the
  authorized deployment or artifact-storage workflow.
- Exclude build artifacts during Git finish; Git finish or this instruction
  update alone does not authorize product cleanup. Retain explicit approved
  project exceptions naming output paths and storage approaches.

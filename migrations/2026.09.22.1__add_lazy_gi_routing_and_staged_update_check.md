# Add Lazy GI Routing And Staged Update Check

Migration ID: `2026.09.22.1__add_lazy_gi_routing_and_staged_update_check`

## Purpose

Reduce persistent model context from GI command routing and normal first-task
update checks without weakening mandatory command contracts or accepted
migration application.

## Accepted Guidance

- Keep `COMMANDS.md` as a compact user-facing help index.
- Resolve a specific `gi ...` / `ги ...` command through
  `config/gi-command-routes.json` and `tools/resolve-gi-command.ps1`.
- Select the longest matching alias so specific commands such as
  `gi start sprint` and `gi config service off` take precedence over shorter
  prefixes.
- Return only the selected compact contract and mandatory context files in one
  resolver invocation. Do not load the full detailed command reference for a
  specific command.
- For first-task update checks, compare installed metadata version with accepted
  `VERSION.md` first. Equal versions return `pending migrations: 0` without
  reading changelog, index, migration directory entries, or migration bodies.
- When the accepted version is newer, enumerate unapplied migration IDs and
  read only the pending migration files needed for application.

## Source Files And Project Targets

- Update project `AGENTS.md` from `templates/AGENTS.template.md` loading rules.
- Copy `COMMANDS.md`, `config/gi-command-routes.json`,
  `tools/resolve-gi-command.ps1`, and `patterns/GI_COMMAND_CONTRACTS.md`.
- Update `patterns/AGENTS_RUNTIME/07-startup-and-scope.md`,
  `tools/check-instruction-kit-updates.ps1`, and `tools/agent-start.ps1` from
  their shared source templates.
- Record this migration and version in
  `tools/project-memory/instruction-kit.json` after application and verification.

## Merge And Conflict Rules

Preserve project-local command additions by adding explicit manifest routes and
mandatory project-local files. Do not replace a more specific project command
contract with a generic shared route. Preserve update checks that are stricter
or use an authoritative project-local source, but keep the equal-version fast
path and zero-pending report. If a state-changing command cannot resolve its
manifest or mandatory files, stop that command and report the missing path.

## Verify

- Parse the route manifest and instruction-kit metadata as JSON.
- Confirm every route alias resolves deterministically and every routed file
  exists.
- Confirm `gi start sprint` does not resolve as plain `gi start`.
- Confirm an equal-version update check succeeds without a migrations folder
  and reports zero pending migrations.
- Confirm a newer accepted version enumerates the pending migration ID.
- Run `tools/test-gi-context-routing.ps1`,
  `tools/test-instruction-kit-bootstrap.ps1`, and `git diff --check`.

## Rollback

Restore the previous command loading and update-check rules, remove the route
manifest and resolver only when no project-local routes depend on them, and
restore metadata/version/changelog together. Preserve unrelated local command
extensions and project files.

# Require Permission For Desktop Computer Use

Version: `2026.11.27.1`

## Apply

1. Merge the `Computer Use` section from
   `patterns/AGENTS_RUNTIME/03-rule-precedence.md` into the installed module.
   Preserve project-specific rules that add restrictions. Apply the explicit
   user permission requirement even where local guidance recommends desktop use.
2. Merge the web verification and client refresh guidance from
   `patterns/AGENTS_RUNTIME/12-ui-and-focus.md`. Replace the earlier blanket
   restriction on automatic web UI inspection with the distinction between a
   built-in or headless browser and desktop interaction.
3. Merge `mandatory_hook_max_chars` from `config/gi-context-budgets.json` and
   its use in `tools/invoke-gi-lifecycle-hook.ps1` together. Keep the existing
   `section_max_chars` for ordinary context sections and correction messages.
   This gives the full policy and service prefix room without increasing
   unrelated context budgets.

## Verify And Record

- Run `tools/get-gi-context.ps1 -Phase Work -MandatoryOnly` and verify that
  mandatory context includes the entire `Computer Use` section. Confirm the UI
  module references the shared permission rule and preserves browser-only checks.
- Confirm that project-specific instructions and settings are preserved. Record
  installation after these checks pass. Use existing hook activation or manual
  loading. Installation verification uses text commands and requires no desktop
  interaction.

# Harden Lazy Context And Routing

Migration ID: `2026.09.22.4__harden_lazy_context_and_routing`

## Purpose

Correct regressions found after the lazy startup-context optimization without
restoring the previous large fixed context or multiple helper invocations.

## Accepted Guidance

- Enforce per-section and final packet character ceilings at runtime, including
  summaries that contain a single oversized line, and mark truncation.
- Stop context assembly when the staged instruction update check fails; never
  append a successful startup-completion marker after that failure.
- Inspect Git state without overriding the repository's line-ending policy.
- Copy `BOOTSTRAP.md` into fresh kits so the installed `gi init` route has all
  mandatory context.
- Treat explicit skipped migrations as pending even when installed and accepted
  versions are equal.
- Compare migration version prefixes numerically, using the full migration ID
  only as a deterministic tie-breaker.
- Keep documented plan, full/release/system test, testing-task, and Russian
  task-manager aliases represented in the route manifest.

## Source Files And Project Targets

- Copy `BOOTSTRAP.md`, `tools/get-gi-context.ps1`,
  `templates/check-instruction-kit-updates.template.ps1`,
  `config/gi-command-routes.json`, and `config/gi-context-budgets.json` from the
  accepted shared source.
- Update installed metadata copied-file lists and migration checkpoint only
  after the affected routing, bootstrap, update, and context tests pass.

## Verify

- Run `tools/test-gi-context-routing.ps1` and
  `tools/test-instruction-kit-bootstrap.ps1`.
- Confirm a one-line oversized handoff is truncated within the start budget.
- Confirm a clean CRLF file is not reported modified.

## Rollback

Revert the builder, updater, routing, bootstrap mapping, budgets, metadata,
documentation, version, and tests together. Do not retain a checkpoint for this
migration unless every accepted behavior is present.

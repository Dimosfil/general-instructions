# Compact Runtime Context Pipeline

Migration ID: `2026.09.22.2__compact_runtime_context_pipeline`

## Purpose

Reduce fixed instruction input and repeated tool-loop context while preserving
accepted GI behavior, command safety, migration compatibility, and startup
restore evidence.

## Accepted Guidance

- Keep root and copied `AGENTS.md` files as bounded routing entrypoints. Detailed
  operational rules belong in focused runtime modules.
- Replace operational loading of combined 07/08/09 modules with their focused
  startup/scope, config/task/sprint, and operation-family modules. Retain the
  combined files only as compatibility indexes without operational rules.
- Use `tools/get-gi-context.ps1` for a GI command. One invocation returns the
  staged update status and selected route packet; `gi start` additionally gets
  the latest bounded handoff summary and compact Git snapshot.
- Store migration progress with schema v2: an `applied_through` checkpoint plus
  `additional_applied_migrations` and `skipped_migrations` exceptions. Update
  tooling must continue reading legacy `applied_migrations` arrays.
- Enforce entrypoint, metadata, module, and route-packet ceilings from
  `config/gi-context-budgets.json` in executable regression tests.

## Source Files And Project Targets

- Update project `AGENTS.md` from `templates/AGENTS.template.md` while preserving
  project description, local paths, commands, and stricter local rules.
- Copy `config/gi-command-routes.json`, `config/gi-context-budgets.json`,
  `tools/get-gi-context.ps1`, `tools/resolve-gi-command.ps1`, all focused
  `patterns/AGENTS_RUNTIME/07-*.md`, `08-*.md`, and `09-*.md` modules, and the
  update-check script from its shared template.
- Convert instruction-kit metadata to migration-state schema v2 only after the
  migration changes and verification are complete.

## Merge And Compatibility Rules

Preserve project-local routes and their mandatory files. Move any project-local
operational additions from a combined compatibility file into the matching
focused module before replacing that combined file. Keep stricter local safety,
authorization, deployment, and verification rules. Legacy metadata remains
valid input; successful recording may rewrite it to schema v2.

## Verify

- Parse route, budget, and instruction-kit JSON.
- Confirm no live route loads a combined 07/08/09 compatibility index and every
  routed file exists.
- Confirm legacy and schema-v2 migration metadata both identify pending items
  correctly, and recording produces schema v2 without the legacy array.
- Run `tools/test-gi-context-routing.ps1`,
  `tools/test-instruction-kit-bootstrap.ps1`, PowerShell syntax checks, and
  `git diff --check`.

## Rollback

Restore the previous entrypoints, route manifest, combined runtime modules,
metadata, scripts, version, and changelog together. Preserve project-local
module additions and do not remove the compatibility indexes while older
projects or tooling still reference them.

# Mandatory Horizontal Raw Table Output

Version: `2026.11.20.6`

## Accepted Contract

Default raw database output to a rendered horizontal Markdown table directly
in the response, with original columns across the header and records down the
rows. JSON returned by a database tool/driver does not change the response
format. Use JSON output only when the user explicitly requests it.

## Apply

1. Merge the `Database Raw Output` section from
   `patterns/AGENTS_RUNTIME/03-rule-precedence.md` into the installed mandatory
   task rules. Load the full database rules before querying/responding even
   when raw is part of a startup request. Keep this section in mandatory
   Work/Complete context rather than only an optional routed module.
2. Merge the horizontal Markdown rendering wording from
   `patterns/AGENTS_RUNTIME/07-scope-and-evidence.md`. Use real Markdown table
   syntax outside code fences; do not substitute arrays, object dumps, lists or
   attachments. Preserve the default for a single record and for JSON tool
   results. Preserve selection semantics, all original fields/values, horizontal
   orientation, disclosed limits, exact/partial matching and explicit JSON mode.
3. Advance fresh-bootstrap template version/checkpoint to this release.
   Preserve unrelated project settings and instructions.

## Verify And Record

- Verify Work, Complete, startup and mandatory-only packets contain the new
  mandatory routing section and link to the full raw database contract.
- For source maintenance run routing/context-budget, task-verification,

  tests into consuming projects just to install the rule.
- Record after file delivery passes. Packet delivery checks do not establish

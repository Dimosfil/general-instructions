# Require Windowless Windows Git

Version: `2026.11.21.1`

## Apply

1. Add the Windows Git requirement to the local `AGENTS.md`. Merge the new
   mandatory section in `patterns/AGENTS_RUNTIME/03-rule-precedence.md` and
   the launch requirements in `patterns/AGENTS_RUNTIME/05-windows-command-policy.md`.
   Preserve other project rules.
2. Merge the Windows command from each of the four canonical GI definitions in
   `.codex/hooks.json`, leaving unrelated hooks intact. Update the shared
   `tools/invoke-gi-lifecycle-hook.ps1` and `docs/gi-lifecycle-hooks.md` from the
   accepted source. OpenCode uses the same shared helper.

## Verify And Record

- Verify the Git rule in Work, Complete, startup, and service-context packets.
- Verify that the Windows Codex entrypoint finds the project root from a nested
  directory without Git and that the shared hook uses windowless native Git
  for both passing and failing completion checks.
- Record the installation after delivery checks pass. Report Codex trust for
  changed definitions and OpenCode reload separately from file installation.

Migration ID: `2026.09.27.2__keep_git_finish_git_only`

## Purpose

`2026.09.27.1__verify_contracts_before_git_finish`. Preserve its requirement
to write and verify product contracts during feature implementation.

## Accepted Guidance

- Update focused project-memory contracts while developing meaningful features,
  business rules, workflows, data models, integrations, or architecture. Verify
  affected source, tests, and user documentation before completing that
  implementation task.
- `ги пуш` / `gi push` commits and pushes only the established scoped changes.
  `ги коммит` commits only; `ги только пуш` pushes existing commits only.
- Git finish performs compact status, scope, secret, remote, and final-state
  checks. It does not initiate product-contract auditing, specification
  writeback, implementation, or a new product test cycle. A more specific
  project-local finish-time gate still applies when expressly required.

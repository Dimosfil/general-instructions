# Require Unity Live Connection Verification

## Purpose

Use official Unity tooling first and distinguish configured MCP, live Editor
connectivity, and tools callable in the current chat for every Unity project.

## Source Files

- `patterns/AGENTS_RUNTIME/20-unity-projects.md`
- `templates/AGENTS.template.md`
- `templates/instruction-kit.template.json` (fresh-install baseline)

## Project Files And Merge Rules

1. Copy or merge `patterns/AGENTS_RUNTIME/20-unity-projects.md` into the same
   project-local path. Preserve more specific project-owned controls.
2. Merge the Unity module loading bullet into the project's `AGENTS.md` loading
   contract. Load it before Unity work; non-Unity work needs no extra context.
3. Preserve local Unity runbooks and integration contracts. Merge any equivalent
   existing rule without duplication; resolve conflicts explicitly rather than
   overwriting project-owned instructions.
4. Require official CLI/Pipeline tooling first, read-only target verification,
   and separate checks of protocol tools and current-chat tools. Diagnose an
   unavailable connection before proposing installation/configuration changes.
5. Do not install packages, start/stop Editors, change Play Mode or scenes, or
   rewrite global MCP settings to apply this instruction-only migration.
6. Include the new module in metadata `copied_files`; advance installed version
   and migration state only after applying and verifying the file changes.

## Verification

- Verify that `AGENTS.md` loads the existing Unity module before Unity work.
- Review these cases against the module: configured server without an Editor;
  handshake with zero tools; live CLI/protocol connection without chat tools;
  valid tools returning the wrong project; and successful current-chat checks.
  None may be reported as full current-chat connectivity except the last case
  with the intended project. Failure diagnosis must preserve Editor state.
- Run `git diff --check` when Git is available. In the shared library, run the
  existing bootstrap and context-routing checks to verify distribution and
  bounded loading. Live Unity execution is not required for this text update.

## Conflicts And Rollback

Apply idempotently and preserve stricter local controls. Report unsafe merge
conflicts and leave this migration unapplied. Roll back only its owned additions
and corresponding metadata; preserve unrelated changes and Editor configuration.

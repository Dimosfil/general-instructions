# Raw SQL Result Orientation

Version: `2026.11.20.4`

## Accepted Contract

Render raw database tables like SQL query results: original column names across
the header, one returned record per row, with the query's column and row order.
For `SELECT *`, preserve schema column order. Keep wide results complete in one
table, with horizontal scrolling where the viewer supports it.

## Apply

1. Merge the result-orientation sentences into the raw database rule in
   `patterns/AGENTS_RUNTIME/07-scope-and-evidence.md`. Prohibit transposing
   fields into rows and records/providers into columns, comparison cards,
   separate per-record tables and dropping columns to fit the viewport unless
   the user explicitly requests that presentation.
2. Preserve read-only selection, original names/values, explicit limit
   disclosures and the existing `raw JSON` override.
3. Advance fresh-bootstrap template version/checkpoint to this release while
   preserving unrelated instructions and project settings.

## Verify And Record

- Review that multiple records with multiple fields remain records down rows
  and fields across columns, including wide results; raw JSON remains JSON.
- Run whitespace, fixed-baseline release-order, routing/context-budget and
  bootstrap checks for source maintenance.
- Record installation after file verification. No database writes or new query
  are required for this presentation-only instruction change.

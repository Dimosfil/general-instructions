# Raw Table Default Output

Version: `2026.11.20.3`

## Accepted Contract

Display database `raw` / `рау` results as a table by default. Use JSON only
when explicitly requested, including `raw JSON`, `рау JSON` and `рау джисон`.
Preserve the selected rows, original columns and stored values in both formats.

## Apply

1. Merge the output-format sentences of the raw database rule in
   `patterns/AGENTS_RUNTIME/07-scope-and-evidence.md`. Use original column
   names as table headers and one database row per table row. Preserve the
   existing read-only selection, access, disclosure and value-preservation rules.
2. Update fresh-bootstrap template version and migration checkpoint to this
   release. Preserve unrelated project settings and instructions.

## Verify And Record

- Check that a plain raw request produces a table and an explicit raw JSON
  request produces JSON, with identical selected rows, columns and values.
- Run whitespace and source release-order checks; verify routing/context budgets
  and bootstrap delivery for the changed runtime module.
- Record installation after file checks pass. This instruction-only change
  requires no database writes or new live query.

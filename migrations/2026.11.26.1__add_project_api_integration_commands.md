# Add Project API Integration Commands

Version: `2026.11.26.1`

## Apply

1. Merge the `custom-integration` route from `config/gi-command-routes.json`,
   its implementation from `tools/resolve-gi-command.ps1`, and the help row
   from `COMMANDS.md`. Preserve local routes and help entries.
2. Merge the Project API Integration Commands section from
   `patterns/API_KEY_SECRET_SAFETY.md`. Install or merge
   `templates/CONNECTED_PROJECTS.template.md` and add it to the local
   metadata's `copied_files` if absent.
3. Preserve the project's existing integration registry, runbooks, and
   credentials. A project owner can opt existing entries into the command by
   adding the template fields.

## Verify And Record

- Run `tools/get-gi-context.ps1 -CommandText 'ги кастом' -SkipUpdateCheck`
  and confirm it loads the new contract and lists registered integrations or
  reports that the project registry is unavailable.
- Confirm the project registry and other local rules are preserved. Verify
  selection using a local entry with non-secret references if available.
  Activation requires no authenticated request or hook reconfiguration.
- Record installation after the local delivery checks pass.

# Add OpenCode GI Lifecycle Hooks

Version: `2026.10.25.1`

## Purpose

Deliver current mandatory GI context and automatic pre-completion review through
OpenCode 1.x, reusing the existing lifecycle engine instead of duplicating rules.

## Apply

Apply the accepted [installation/host applicability contract](README.md#installation-and-host-applicability).
OpenCode loading/live checks below establish runtime readiness, not installation
recording. Their absence in Codex does not block verified file installation.

1. Preserve project instructions, other plugins, host configuration and local
   review preferences. Do not install into global or unrelated project folders.
2. Copy `.opencode/plugins/gi-lifecycle.js` and `docs/gi-opencode-hooks.md` into
   the same relative paths. If the GI plugin already differs, inspect and merge
   its owned behavior; do not overwrite project customizations silently.
3. Merge the accepted changes to `tools/invoke-gi-lifecycle-hook.ps1`: optional
   validated `host` (`codex` by default, or `opencode`), host-specific ignored
   state, exclusion of both hosts' state from work fingerprints, and OpenCode
   `task` forwarding. Preserve existing Codex handlers and semantics. The context
   builder and module 03 must remain current; missing files are a concrete blocker.
4. Add `.opencode/.gi-hook-state/` and `.opencode/node_modules/` to the project's
   `.gitignore` without changing other ignore rules.
5. Merge only the marked mandatory invocation block from the current
   `templates/AGENTS.template.md`; acknowledge active GI hooks for either host
   while keeping manual Work/Complete as the fallback. Keep other local content.
6. Add the new plugin/docs paths to `copied_files`. Update user-facing setup links
   and relevant project memory without copying source-library development tests
   into product folders.
7. Verify shared engine protocol and an installed-kit scenario. Reload OpenCode
   with plugins enabled, then verify Work -> review required -> Work -> completion
   allowed. Follow `docs/gi-opencode-hooks.md` for the real 1.15.7 loop test,
   structured-output exclusion, streamed-text limits and privacy. Report configured
   separately from active/live-tested; never fabricate a successful model review.
8. Advance installed version/checkpoint only after the scoped migration passes
   its applicable checks. Keep opt-outs and skipped migrations intact.

## Verification

- Run source regressions for OpenCode adapter contracts, the real response loop,
  Codex lifecycle protocol and bootstrap preservation/idempotence.
- Confirm no external provider, credential, global config or unrelated project
  is needed by the fixture; generated state must remain ignored.
- Keep existing context budgets and mandatory whole-task requirements unchanged.

# Single Final Response And Quiet Completion

Version: `2026.10.25.7`

## Accepted Contract

Perform required checks and the enabled semantic review internally before one
final response. Use plain text or Markdown without raw HTML. Summarize large
file inventories by count, directory and reason; name individual paths when
requested or necessary for specific changes or blockers. Keep the full internal
inventory and honest reporting of unfinished selected work.

Successful lifecycle checks must not generate a chat continuation or duplicate
answer. This supersedes earlier always-blocking Stop review contracts, including
the compact-reminder contract. Hooks enforce context delivery and automated
checks; they do not independently prove the agent performed semantic review.
Actual check failures and unavailable context remain visible and unverified.

# Complete Cyrillic Alias Parity

Migration ID: `2026.09.22.5__complete_cyrillic_alias_parity`

## Purpose

Ensure Russian GI commands work with both the Latin `gi` and Cyrillic `ги`
prefixes, including the common `ги пуш` finish command.

## Accepted Guidance

- For every route alias whose command body is Russian and whose prefix is
  `gi`, register the equivalent `ги`-prefixed alias on the same route.
- Keep longest-prefix resolution and command contracts unchanged.
- Validate prefix parity across the entire route manifest rather than testing
  only one reported spelling.

## Source Files And Project Targets

- Copy `config/gi-command-routes.json` from the accepted shared source.
- Update `COMMANDS.md` when a newly supported common form belongs in the compact
  user-facing index.
- Advance instruction-kit metadata only after route and bootstrap tests pass.

## Verify

- Resolve `ги пуш` to `git-finish`.
- Confirm every `gi <Russian command>` alias has a matching
  `ги <Russian command>` alias on the same route.
- Run `tools/test-gi-context-routing.ps1`,
  `tools/test-instruction-kit-bootstrap.ps1`, JSON parsing, and
  `git diff --check`.

## Rollback

Revert the added aliases, parity check, metadata, version, changelog, and this
migration together.
